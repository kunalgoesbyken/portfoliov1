## What It Covers

**The Sniffing Phase** — How Merkle trees detect changed files in O(log n) time instead of re-reading 50,000 files on every startup.

**The Butchering Phase** — Why naive line-based chunking destroys semantic meaning, and how tree-sitter AST parsing produces self-contained code chunks (functions, classes, methods).

**The Math Phase** — How nomic-embed-text-v1.5 produces 768-dimensional vectors with INT8 quantization (137MB model, runs on CPU), and why the `search_document:` / `search_query:` prefix trick matters.

**The Filing Phase** — Two indexes working in concert: BM25 for exact keyword matches and HNSW for vector similarity, fused with Reciprocal Rank Fusion (RRF).

**The Instant Grep** — How character n-gram inverted indexes replace ripgrep for sub-millisecond search.

**The Sharing Trick** — How Simhash lets teammates inherit existing indexes without transferring code they don't own.
